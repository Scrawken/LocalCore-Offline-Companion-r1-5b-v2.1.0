# LocalCore-Omni (Model A)

**Capabilities:** Text chat · image understanding · speech input (ASR) · speech output (TTS)
**Base model:** Qwen2.5-Omni-3B — [Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0) (commercially safe)
**Training method:** QLoRA (4-bit) — fits RTX 3060 12GB
**Status:** Scaffold

---

## Why This Base

Qwen2.5-Omni is the only open-weight model that covers all four conversational modalities in one package, using a Thinker-Talker architecture (one model reasons in text, a paired decoder speaks). The 3B size fits our floor-tier ambitions and can be QLoRA fine-tuned on the RTX 3060 today. The 7B variant is the upgrade path once a 24GB+ GPU arrives.

## Data Rules (read before generating anything)

- **Do NOT distill Dolphin's outputs into Omni.** The Llama Community License forbids using Llama-model outputs to improve non-Llama models, and Qwen2.5-Omni is not a Llama derivative. Text persona/behavior data must instead come from:
  1. Self-instruct data generated by the Qwen base itself, guided by human-written persona/system prompts (the persona is *ours* — written by hand, not copied from Dolphin's tuning);
  2. Apache-2.0-licensed instruction datasets;
  3. Hand-written conversation examples.
- Vision, ASR, and TTS teachers are distillation-safe per the table above.
- Every dataset gets a manifest recording teacher, license, generation date, and filters applied. See [data/README.md](data/README.md).

## Training Plan

- **Stage 1 (RTX 3060):** QLoRA on text persona + instruction data. Validate chat quality against `npm run test:chat-model` fixtures.
- **Stage 2 (RTX 3060):** Add vision-description pairs (teacher: Qwen2.5-VL-3B) so image understanding matches current behavior.
- **Stage 3 (RTX 3060, if VRAM allows; else deferred):** Speech pairs (teacher: Whisper for ASR alignment; Piper audio as TTS reference targets).
- **Stage 4 (24GB+ GPU):** Full omni training run, all modalities together; consider 7B variant.

Reference config: [configs/qlora-3b.yaml](configs/qlora-3b.yaml)

## Evals (gate for replacing teachers)

1. Passes existing `test:chat-model`, `test:chat-context`, `test:vision`, `test:speech` fixtures.
2. Persona consistency eval: fixed probe set, human-reviewed.
3. VRAM footprint ≤ current Dolphin + Qwen2.5-VL combined residency (~10.7 GiB observed peak on RTX 3060).
4. Streaming latency on RTX 3060 no worse than current llama.cpp pipeline.
