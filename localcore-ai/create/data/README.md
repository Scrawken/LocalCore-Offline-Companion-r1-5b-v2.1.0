# LocalCore-Create — Data Recipe

Raw and generated datasets live here at runtime but are **git-ignored**. Only this recipe, schemas, and manifests are committed.

## Directory Layout (runtime)

```
data/
  raw/                 ← unfiltered image pools (git-ignored)
  generated/           ← curated training sets with captions (git-ignored)
  manifests/           ← committed: one JSON per dataset version
```

## Datasets

### 1. `style_v1` — LocalCore visual identity (Stage 1)

**Allowed sources only:**

- Our own FLUX.1-schnell generations (Apache 2.0 base → outputs we may use);
- Human-made art created for LocalCore;
- Verifiably license-clean images (CC0 / public domain, source URL recorded).

**No scraped copyrighted artwork. No FLUX.1-dev or SVD-XT outputs** (non-commercial licenses).

**Captions:** generated by Qwen2.5-VL-3B-Instruct (Apache 2.0, distillation-safe), then hand-corrected on a sample. One `.txt` caption per image, kohya-style:

```
raw/style_v1/img_0001.png
raw/style_v1/img_0001.txt   ← "localcore style, soft ambient light, ..."
```

**Target size:** 200–500 images for a style LoRA (quality over quantity).

### 2. `characters_v1` — character consistency (Stage 1b)

Multi-angle / multi-expression sets per recurring character (5–10 images per character). Same caption format, plus a `character_id` tag in the caption so the LoRA learns a nameable token per character.

### 3. Video data (Stage 2 — deferred)

Not started. Base model for the video stage is TBD (SVD-XT is non-commercial). This section will be written when a commercially-safe video base is chosen.

## Manifest Format (`manifests/<name>.json`)

```json
{
  "dataset": "style_v1",
  "created": "YYYY-MM-DD",
  "sources": [{"name": "own-flux-generations", "license": "Apache-2.0", "count": 0}],
  "caption_teacher": "Qwen2.5-VL-3B-Instruct",
  "caption_teacher_license": "Apache-2.0",
  "reviewed": false,
  "notes": ""
}
```

## Curation Rules

- Every image must have a recorded source and license in the manifest — no orphans.
- Hand-review 100% of style images (the set is small; this is the identity of the product).
- Reject blurry, watermarked, or text-heavy images.
- Aspect-ratio diversity: include portrait, square, and landscape so bucketing works.
