# Blender Studio female base mesh

`blender_studio_stylized_female_base.blend` contains only the stylized female
body and eye meshes from Blender Studio's Human Base Meshes v1.4.1 asset bundle.
The selected mesh is used as an editable topology foundation; LocalCore's hair,
face, clothing colors, rig, and VRM metadata are generated separately.

Blender lists the Human Base Meshes bundle as **CC0**. The source and current
license listing are available at:

- https://www.blender.org/download/demo-files/
- https://download.blender.org/demo/asset-bundles/human-base-meshes/

The source bundle was downloaded on 2026-10-20. This LocalCore copy removes the
unused base meshes, cameras, and bundle scene while retaining the three chosen
mesh objects.
